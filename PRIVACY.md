# Politique de confidentialité de Skellock

Dernière mise à jour : 24 juillet 2026

Skellock est une extension indépendante conçue pour ajouter un verrou local par code avant l’accès aux domaines Skello sur un ordinateur partagé. Skellock n’est ni éditée, ni approuvée, ni sponsorisée par Skello.

## Données traitées

Skellock traite uniquement :

- le code d’accès saisi sur l’écran de verrouillage, afin de le vérifier localement en mémoire ;
- le fait qu’une navigation principale vise `https://skello.io` ou l’un de ses sous-domaines, uniquement afin d’afficher l’écran de verrouillage.

Skellock ne lit pas le contenu des pages ou des plannings, les cookies, les identifiants du compte Skello, les données de formulaire du site ou les communications.

## Stockage et durée de conservation

Le code saisi n’est pas enregistré. Il est comparé localement, puis immédiatement abandonné. Les adresses de navigation ne sont ni enregistrées dans un historique propre à l’extension, ni conservées après l’application de la règle de verrouillage.

## Transmission et partage

Le développeur ne reçoit aucune donnée. Skellock n’utilise aucun serveur, service d’analyse, publicité ou outil de suivi. Aucune donnée n’est vendue, louée ou partagée avec un tiers.

## Utilisation limitée

Les données sont utilisées exclusivement pour fournir la fonction de verrouillage décrite ci-dessus. L’utilisation des informations reçues des API Google respecte la Politique relative aux données utilisateur du Chrome Web Store, y compris les exigences d’utilisation limitée.

## Contrôle par l’utilisateur

La fermeture d’un onglet déverrouillé supprime son autorisation temporaire. Un clic sur l’icône Skellock reverrouille immédiatement tous les onglets Skello ouverts. La désinstallation supprime toutes les règles appartenant à l’extension.

## Contact

Pour toute question relative à cette politique, utilisez le [suivi public du projet](https://github.com/keytrap-x86/skellock/issues).
